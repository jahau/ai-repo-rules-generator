# Detection fixtures

These are minimal metadata fixtures, not runnable applications or recommended
dependency versions. Do not install their dependencies. They exercise nested
project detection and intentionally omit check commands where none are declared.

Run `python generate_rules.py examples/monorepo --agent all --diff` to preview
instructions without changing the fixtures. See `docs/samples/` for complete
generated output and `docs/demo.txt` for a captured CLI session.
